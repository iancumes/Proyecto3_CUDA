# Proyecto 3 CUDA · Clasificación de señas ASL

Proyecto de CC3069, Computación Paralela y Distribuida, UVG. El equipo está integrado por Ian Cumes, Javier Valladares y Nery Molina.

El punto de partida es [Lab3Datos](https://github.com/Javiervalladares1/Lab3Datos/tree/e13d60cc606abdfd8f8a937cae79a091204501c1). Se conserva su historial. [El README y el flujo original](https://github.com/Javiervalladares1/Lab3Datos/blob/e13d60cc606abdfd8f8a937cae79a091204501c1/README.md) describen el laboratorio de Data Science.

El experimento de CC3069 usa CNN2 y el dataset público [ASL Alphabet](https://www.kaggle.com/datasets/grassknoted/asl-alphabet). El manifiesto estratificado fija qué imágenes recibe cada implementación. Las imágenes y los archivos temporales se generan durante la ejecución.
